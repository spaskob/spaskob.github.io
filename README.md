# Spas Bojanov — Developer blog

A small, responsive personal blog built with plain HTML and CSS. It is ready to publish
with GitHub Pages from the repository root.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Make it yours

- Update the introduction and About section in `index.html`.
- Add posts in the Writing section as you publish them.
- Change the type and color settings at the top of `styles.css`.

The site uses Newsreader, DM Sans, and DM Mono from Google Fonts, with local system
fallbacks if those fonts are unavailable.
