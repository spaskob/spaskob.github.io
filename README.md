# Spas Bojanov — Developer blog

A simple, responsive personal blog built with plain HTML and CSS, published with
GitHub Pages from the repository root.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Make it yours

- Update the introduction in `index.html`.
- Add posts under Recent as you publish them.
- Adjust the colors, type, and spacing in `styles.css`.
